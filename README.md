# AppLock

AppLock lets you protect individual Android apps with a PIN, password, pattern, or biometrics. It supports an unlock timer and optional protection against uninstalling. It runs without root.

[Download the signed APK](https://github.com/teleboost464-ui/AppLock/releases) · [Build and release guide](MAINTAINING.md)

## Choose which apps to protect

Tap **+** in AppLock and use the filter below the search field.

- **Essential** shows apps with launcher icons, including preinstalled apps.
- **Installed** shows user-installed apps.
- **System** shows system apps and components.

AppLock remembers your last filter across restarts. Your checked apps stay selected as you switch filters. Tap **Protect** when you’re ready.

## Install or update

Choose an APK from the [fork’s releases](https://github.com/teleboost464-ui/AppLock/releases). The signed previews use the same fork key and can update earlier previews from this repository. If your current copy uses a different key, Android requires uninstalling it before switching. Uninstalling clears its local AppLock settings.
